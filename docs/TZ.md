# Техническое задание — интернет-магазин «Миска»

**Вариант:** собственный — магазин корма и лакомств для животных  
**Особенность:** подбор корма по виду животного, возрасту и цене  

## Назначение

Веб-приложение для просмотра каталога кормов, фильтрации товаров, оформления корзины и регистрации покупателей.

## Страницы

| Страница | Файл | Содержание |
|----------|------|------------|
| Главная | `index.html` | О магазине, навигация, 6 популярных товаров |
| Каталог | `catalog.html` | ≥12 товаров, фильтры (вид, возраст, цена), сортировка |
| Товар | `product.html` | Описание, состав, характеристики, цена |
| Корзина | `cart.html` | Выбранные позиции, количество, итоговая сумма |
| Контакты | `contacts.html` | Адрес, телефон, режим работы, форма обратной связи |

## Функциональность по практикам

### ПР 1 — статическая вёрстка
- Семантическая разметка, общий `css/style.css`
- Адаптив от 360 px, Flexbox/Grid
- Собственный логотип, меню на всех страницах

### ПР 2 — динамика и API
- Фильтрация и сортировка каталога без перезагрузки
- Корзина в `localStorage`, FAQ-аккордеон
- Формы с проверкой полей: обратная связь, оформление покупки
- Внешний API: курсы ЦБ РФ (`cbr-xml-daily.ru`) + пересчёт цен в $ / €
- Карта магазина: OpenStreetMap на странице контактов
- Вход/регистрация — в ПР 3

### ПР 3 — сервер и БД
- FastAPI + SQLite
- Таблицы: `users`, `products`, `orders`, `order_items`
- ≥15 товаров в каталоге, данные страниц с сервера
- Регистрация/вход, пароль только как bcrypt-хеш
- После входа: профиль и свои заказы

### ПР 4 — развёртывание
- Настройки в переменных окружения (`.env.example`)
- `Dockerfile` / `docker-compose.yml` / `render.yaml`
- Публичный HTTPS-адрес и тестовый аккаунт в README
