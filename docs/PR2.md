# ПР 2 — поведение страницы и внешние данные

## Что сделано

### Часть 1. Поведение
1. **Две интерактивные формы**
   - обратная связь (`contacts.html`)
   - оформление покупки (`cart.html`)
2. **Проверка данных** — ошибки рядом с полем, без `alert`
3. **Без перезагрузки страницы**
   - фильтр и сортировка каталога
   - корзина (добавление / изменение количества / удаление)
   - раскрывающийся блок FAQ на главной

Форма входа по заданию относится к **ПР 3**, страница `auth.html` пока заготовка.

### Часть 2. API
- Источник: **курсы валют ЦБ РФ** — `https://www.cbr-xml-daily.ru/daily_json.js`
- Запрос через `fetch`, есть состояние «Загрузка…»
- При ошибке сети показывается сообщение, сайт продолжает работать
- На главной и в каталоге цены можно смотреть в ₽ / $ / €

## Как показать на защите
1. Каталог → сменить фильтры и сортировку
2. Контакты → отправить пустую форму, показать ошибки у полей
3. Корзина → оформить заказ с неверным телефоном, затем с верным
4. Главная → блок курсов ЦБ; в DevTools отключить сеть и нажать «Обновить курсы»
